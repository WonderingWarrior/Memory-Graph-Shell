# Memory Graph Shell — free public copy

A small, honest memory shape for an AI agent: three buckets (Facts / labeled
theories / open questions), a context-floor trim, and a lint that flags a guess
dressed as a fact.

Free, public, no strings. Read `SKILL.md` first.

## One-command install (copy into your skills folder)

```bash
git clone https://github.com/WonderingWarrior/Memory-Graph-Shell.git /tmp/mgs && cp -r /tmp/mgs/memory-graph-shell <your_skills_dir>/
```

Then:
```bash
chmod +x memory-graph-shell/scripts/graph.sh
memory-graph-shell/scripts/graph.sh init ~/memory
```
